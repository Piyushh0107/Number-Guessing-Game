# Number Guessing Game 🎯

A Python-based number guessing game available in GUI versions.

## Features
- Random number generation (1–100)
- Difficulty levels (CLI version)
- Attempt tracking
- Input validation
- Replay option
- GUI version built using Tkinter

## Technologies Used
- Python
- Tkinter

## How to Run

CLI Version:
python number_guessing_game.py

GUI Version:
python number_guessing_gui.py
